# Python OS Automation Utilities

A collection of Python scripts for automating common
operating-system and IT support tasks.

## Features

- Automatic file organisation
- Log-file analysis
- IP-address extraction
- System health monitoring

## Requirements

Python 3.12+

## Installation

Clone the repository:

git clone ...

Install dependencies:

pip install -r requirements.txt

## Usage

Run the file organiser:

python file_organizer.py

Run the log analyser:

python log_analyzer.py

Run the system health checker:

python system_health.py
